# narratives/

Prose written by Claude in a Code session from the season logs and the chronicle, at the director's request through the console's Narrate control. Nothing here is generated by a workflow: the console produces a block of instructions, the director pastes it into a Claude Code session, and the resulting file is committed and merged like any other change.

One file per season range, `NNNN-NNNN.md`, with front matter naming the seasons it covers and the tone it was written in. The chronicle page offers a **Read** toggle on every season a narrative covers.

Hard rule 9 governs what may be in one: house detail that is not in `hoc.db` does not appear in the prose.
