Console

The director's controls

Everything here dispatches the Engine workflow, which plays the game, runs the tests, exports the site and commits the result. The console never writes to the repository itself, so there is one path by which the game changes and it is the one that checks its work.

Connect

Not connected.

The console needs a fine-grained personal access token with Actions: read and write and Contents: read on this repository. Actions: read and write is what lets it dispatch engine.yml directly; if a token was only granted Contents: read and write instead, the console falls back to a repository_dispatch, which needs Contents only. It is kept in this browser's local storage and sent only to api.github.com — it is never part of this site, and nobody else who opens this page has it. Revoke it any time at github.com/settings/personal-access-tokens.
